BOTTLENECK IDENTIFICATION:
1. apply(axis=1) iterates row-by-row (50,000 function calls)
2. Each row access via Series.__getitem__ is expensive (350,000 calls)
3. No vectorization - misses numpy's SIMD capabilities

ROOT CAUSE:
The regression replaced vectorized numpy operations with Python-level iteration.
Vectorized pandas/numpy operations process entire columns at once (1 operation)
vs row iteration (50,000 operations).

SOLUTION:
Revert to vectorized numpy operations in EngagementScorer:
- Use element-wise numpy operations on entire Series
- Eliminate apply(axis=1)
- Expected performance: ~0.02s (20x faster)
